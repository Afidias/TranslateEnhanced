# TranslateEnhanced

TranslateEnhanced 是一款面向 Aliucord 的 Discord 消息翻译插件。它支持 Google Translate 和 OpenAI 兼容的大模型接口，可以翻译单条消息，也可以按频道自动翻译聊天内容。

## 主要功能

- 手动翻译消息，并可随时切换回原文
- 自动翻译当前私聊或频道，包括已加载的历史消息和后续新消息
- 使用大模型时自动合并批量请求；失败时可降级到 Google Translate
- 翻译结果保留可点击链接、Emoji、提及、自定义表情和时间戳
- 对翻译结果不满意时可选择“重新翻译”
- 可选择是否自动翻译自己发送的消息
- 为每个频道或私聊分别设置提示词和术语对照表
- 根据当前聊天内容自动生成频道提示词与常用术语
- 本地缓存翻译结果，并支持按频道或全部清除
- 提供中文和英文设置界面，整体样式与 Discord 保持一致

## 安装

使用本插件需要：

- Android 设备
- Aliucord
- Discord 版本 `126021`

下载正式版插件包：

**[下载 TranslateEnhanced.zip](https://github.com/kizfive/TranslateEnhanced/raw/builds/TranslateEnhanced.zip)**

将 `TranslateEnhanced.zip` 放入：

```text
/sdcard/Aliucord/plugins/
```

然后完全重启 Discord。后续版本可以通过 Aliucord 的插件更新功能安装。

## 快速开始

1. 打开 Aliucord 插件设置中的 **Translate Enhanced**。
2. 选择默认目标语言。
3. 选择翻译后端：
   - **Google Translate**：无需填写 API 配置，适合开箱即用和追求速度。
   - **大模型**：填写兼容 OpenAI API 的 Base URL、API Key 和模型名称。
4. 长按一条消息，在菜单中选择 **翻译此消息**。
5. 如果要持续翻译当前聊天，在消息菜单中开启 **自动翻译此频道**。

## 大模型配置

插件使用 OpenAI 兼容接口，请在设置中填写：

- **Base URL**：服务商提供的接口地址，带不带 `/v1` 均可
- **API Key**：服务商提供的密钥
- **模型名称**：可以手动输入，也可以通过“获取可用模型”选择

建议先使用“测试连接”确认配置有效。大模型请求失败时，插件会自动尝试 Google Translate，并在批量完成提示中显示降级数量。

> 使用第三方大模型服务意味着待翻译的消息会发送给对应服务商。请自行确认服务商的隐私政策和数据处理规则。

## 自动翻译

在任意消息的长按菜单中可以开启或关闭当前聊天的自动翻译。自动翻译开启后：

- 会处理当前已加载的历史消息
- 会继续处理新收到的消息
- 大模型后端会把短时间内的多条消息合并成批量请求
- Toast 会提示开始、请求中和本批完成等阶段
- 关闭后会清除待处理任务，并忽略仍在途的大模型结果

设置页面中的“翻译自己发送的消息”默认关闭，可以按需开启。

## 频道翻译配置

打开插件设置中的 **频道提示词 / 术语表 / 缓存管理**，可以按频道或私聊分别管理翻译规则。

频道列表会显示：

- 服务器频道的服务器头像与频道名
- 私聊对象的头像与用户名
- 群聊头像与群聊名称

进入具体频道后可以：

- 编写描述聊天话题、语气或翻译要求的专属提示词
- 在术语对照表中指定“原术语 → 固定译法”
- 让大模型分析当前已加载的最近消息并自动生成配置
- 清除该频道的翻译缓存或配置

频道提示词和术语表目前只影响大模型后端。

## 链接、Emoji 与其他内容

插件会在翻译前记录消息中的链接和 Discord 特殊标记，并在翻译后恢复。译文中的 URL 会重新按 Discord 消息格式渲染，因此可以点击，并会在中文、全角标点或 Emoji 处正确结束。

设置中的“链接保护”开启后，URL 不会发送给翻译服务，而是使用占位符在原位置恢复；关闭时 URL 会随原文发送，并在翻译完成后校验和补回。

## 缓存与日志

翻译缓存保存在：

```text
/sdcard/Aliucord/translate_cache.json
```

调试日志保存在：

```text
/sdcard/Aliucord/translate.log
```

遇到问题时，请在插件设置中开启 **Debug Mode**，复现问题后附上 `translate.log`。日志可能包含消息文本、接口错误等调试信息，分享前请先确认其中没有隐私内容或 API Key。

## 常见问题

### 为什么译文和原文完全一样？

可能是文本本来已经属于目标语言，也可能是模型原样返回。可以长按该消息并选择 **重新翻译此消息**，该操作会绕过旧缓存并要求模型重新翻译。

### 为什么自动翻译会降级到 Google？

常见原因包括 API 配置错误、模型输出格式不符合要求、请求超时或服务商限流。请先测试连接，再查看 `/sdcard/Aliucord/translate.log` 中的具体状态码。

### 为什么没有翻译更早的历史消息？

插件只能处理 Discord 当前已经加载或滚动加载出来的消息。继续向上滚动后，新显示的历史消息会进入自动翻译流程。

### 如何反馈问题？

请在 [GitHub Issues](https://github.com/kizfive/TranslateEnhanced/issues) 描述复现步骤、Discord/Aliucord 版本和所用翻译后端；如有可能，请同时提供经过隐私检查的 `translate.log`。
